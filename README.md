# Personal Finance Tracker - Frontend

This is the frontend for the Personal Finance Tracker application, built with React, Tailwind CSS, and shadcn/ui.

## Prerequisites

- Node.js

## Getting Started

1.  **Clone the repository.**

2.  **Navigate to the `frontend` directory:**
    ```bash
    cd frontend
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Run the application:**
    ```bash
    npm start
    ```

The application will be running at `http://localhost:3000`.

## Features

-   **Authentication:** Login, Register, Forgot/Reset Password pages.
-   **Dashboard:** Overview of finances with charts and stats.
-   **Transactions:** View, add, edit, and delete transactions.
-   **Budgets:** Set and track monthly budgets.
-   **Settings:** Toggle between light and dark mode.
-   **Responsive Design:** Works on mobile and desktop.
-   **Protected Routes:** Pages are protected and require authentication.
-   **Token Auto-Refresh:** The application will automatically refresh access tokens.

## Tech Stack

-   React (Create React App)
-   React Router
-   Tailwind CSS
-   shadcn/ui
-   Recharts
-   Axios
-   React Context for state management
